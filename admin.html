Új bejegyzés

Írj új történetet!

Itt tudsz új bejegyzést indítani. A Közzététel gomb a GitHub biztonságos szerkesztőjét nyitja meg, ahol bejelentkezés után elküldheted a szöveget.

  1. Adj címet a történetnek.
  2. Írd meg a bejegyzést.
  3. Ha képet is szeretnél, a GitHub szövegmezőjébe csatolhatod.
  4. A végén nyomd meg a „Submit new issue” gombot. Ezután a bejegyzés megjelenik a főoldalon.

Új bejegyzés közzététele

Fontos: a próbaoldal és a bejegyzések nyilvánosak. Ne írj személyes, egészségügyi vagy más bizalmas adatot. A bejegyzés a GitHubon is megjelenik.
